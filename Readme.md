# PawfectCare

Pet care management system designed for tracking pet records, health, and services.

## Install

1. Download or clone the project repository

2. Open your terminal or command prompt inside the project folder

3. Install the required dependencies:

	pip install -r requirements.txt
	Features
	Pet Profiles — add and manage detailed records for multiple pets, including breed, age, and medical history

## Service Management 

1. Track appointments
2. Grooming schedules
3. Care routines

## Dashboard Overview
Clean interface to view upcoming tasks and general status

## Features

- **Video / Audio tab** — paste any YouTube URL, pick format (MP4 / MP3 / M4A), pick quality (Best by default), browse save location, download
- **Playlist tab** — audio-only (MP3), names a subfolder, downloads entire playlist
- **History tab** — log of all downloads with path, date, type

## Manual run (if needed)

```
python main.py
```

## Requirements 

- Python 3.8+
